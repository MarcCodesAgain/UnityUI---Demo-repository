# unityui-demo

A minimal showcase app demonstrating every component from [`@marcllopis/unityui`](https://www.npmjs.com/package/@marcllopis/unityui) — a Swiss Minimalism design system built with React, TypeScript, and styled-components.

The goal is simple: show that the package installs from npm and all components work out of the box in a standard Vite + React project.

## Stack

- [Vite](https://vite.dev/) + React 19 + TypeScript
- [`@marcllopis/unityui`](https://www.npmjs.com/package/@marcllopis/unityui) — installed from npm, no local symlinks

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## What's on the page

| Component | What's demonstrated |
|---|---|
| **Button** | All variants (primary, secondary, ghost), sizes, loading and disabled states |
| **Typography** | Full scale from h1 to caption, overline, highlight animation |
| **Badge** | All variants with and without dot indicator |
| **Alert** | info · success · warning · error, dismissible |
| **Avatar** | Sizes and status dots (online, away, offline) |
| **Input** | Controlled text field with label |
| **Select** | Controlled dropdown with options |
| **Checkbox** | Controlled with animated SVG check |
| **Radio** | Controlled group |
| **Spinner** | All four sizes |
| **CountUp** | Animated counters with prefix, suffix, decimals |
| **Card** | Basic and interactive variants with compound sub-components |
| **SpotlightCard** | Cursor-glow effect with custom glow colour |
| **Modal** | Open/close via `useModal` hook, focus trap, scroll lock |
| **CommandPalette** | ⌘K palette via `useCommandPalette` hook, grouped items, keyboard navigation |
